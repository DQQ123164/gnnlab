# 自由问题：图模型能否提升 NTU60 动作识别？

探索 Graph Transformer、GCN 或二者的组合，能否在完整的 NTU RGB+D 60 骨架动作识别任务上取得更高且可复现的准确率。

## 研究问题

人体骨架天然可以表示为时空图：关节是节点，人体连接与跨帧轨迹构成边。GCN 擅长编码局部骨架拓扑，Graph Transformer 则可以建模更长距离的关节关系与时间依赖。

本实验不预设哪种结构一定更好，而是回答一个开放问题：

> 在相同的数据划分、输入模态和训练条件下，Graph Transformer/GCN 能否相对明确的基线提高完整 NTU60 的动作识别准确率？

## 数据集与范围

实验使用完整的 [NTU RGB+D 60 官方数据集](https://rose1.ntu.edu.sg/dataset/actionRecognition/)，而不是 `dsg` 分支中的五分类子集。

- 任务范围：全部 60 个动作类别，共 56,880 个样本。
- 输入模态：每帧包含 25 个关节三维坐标的骨架序列。
- 评估协议：使用官方 Cross-Subject（`xsub`）和 Cross-View（`xview`）划分。
- 数据获取：通过官方页面申请并遵守其学术研究与使用条款；本仓库不分发原始数据。

## 可探索方向

- 以时空 GCN 为基线，研究固定、可学习或样本自适应的邻接关系。
- 使用 Graph Transformer 建模非相邻关节和长时间跨度的动作依赖。
- 组合 GCN 的局部结构先验与 Transformer 的全局注意力。
- 在坐标特征之外，比较骨骼向量、速度或多流特征是否带来稳定收益。

## 比较要求

为了让“提高准确率”的结论可信，候选模型与基线应使用相同的数据划分、输入信息和预处理方式，并报告：

1. `xsub` 与 `xview` 的 Top-1 准确率。
2. 明确的基线、训练配置和最佳模型选择规则。
3. 参数量、计算量或推理开销，避免只比较准确率。
4. 多次运行的均值与波动，而不是只报告单次最佳结果。

最终结论可以是提升、持平或下降；重点是用可复现的实验解释图结构与时序建模对结果的影响。
