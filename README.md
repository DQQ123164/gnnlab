# 动态骨架图实验

- 本实验是静态骨架图实验的进阶任务，以连续人体骨架序列五分类为目标，核心任务是参考 ST-GCN 论文复现一个基础的时空图卷积网络。学生需要理解 ST-GCN 的基本思想，并结合本实验提供的标准数据接口，自行完成骨架图构建、空间图卷积、时间卷积、残差连接和动作级聚合，而**不是直接运行已经封装好的完整模型**。
- 模型需要同时学习**帧内关节的空间关系**与**跨帧关节的运动变化**，重点理解图神经网络如何由静态骨架图扩展至**时空骨架图**，以及关节特征如何在**空间和时间两个维度上传播**。完成基础复现后，可以进一步尝试调整邻接关系、时间建模方式或网络结构。

## 实验目的

- **实验要求**：使用预处理后的连续骨架序列训练图模型，识别从 `NTU RGB+D 60` 中抽取的 `A059`、`A030`、`A016`、`A005` 和 `A027` 五类动作。模型应以每帧的 25 个关节为节点，依据人体骨架拓扑进行图卷积或等价的空间消息传递；**跨帧时间变化可使用 TCN、RNN、Attention 或时序消息传递进行建模**。最后通过动作级聚合（readout）得到序列表示，并由分类层完成五分类。`xsub` 和 `xview` **两种官方协议均需独立完成训练与测试**。
- **建模限制**：原始 `.skeleton` 文件和预处理后生成的 `.npy` 文件仅作为数据来源与存储接口，主模型训练前必须构建帧内关节图和跨帧时间关系。**不得将骨架坐标直接展平后使用传统机器学习**、MLP 或其他不含图结构的模型作为主方案（非图模型可以作为对比基线）。
- **评判标准**：分别报告 `xsub` 和 `xview` 固定测试集上的 Top-1 Accuracy。两种协议（`xsub` 和 `xview`）的 Top-1 Accuracy **均达到 80% 及以上**，即视为完整完成本实验要求。同时报告各类别的 Precision、Recall、F1 和混淆矩阵。需要调参、选择模型或早停时，只能从相应协议的训练集中划分验证集，**测试集仅用于最终评估**。模型之间只能在相同的数据划分、输入和预处理条件下比较。

## 数据准备与划分

DSG 直接从 NTU RGB+D 官方原始骨架压缩包中生成。本实验使用 NTU RGB+D 60 中的五类动作，因此只需准备 `nturgbd_skeletons_s001_to_s017.zip`；另一个压缩包存放的是 NTU RGB+D 120 新增类别，本实验不会使用。

脚本会生成两套官方评估划分：`xsub` 按受试者划分，`xview` 按摄像机视角划分。

### 1. 生成数据划分

将压缩包放入 `gnnlab/dataset/`，然后在项目根目录指定该 ZIP 文件运行：

```bash
python3 tools/split_dsg_from_ntu.py \
  --source-zip dataset/nturgbd_skeletons_s001_to_s017.zip \
  --workers 8
```

该命令会并行筛选五类动作并生成两套数据划分，结果默认保存到 `dsg/`；`--workers` 可根据机器性能调整。

### 2. 运行预处理

完成划分后，将 `.skeleton` 文件转换为模型可读取的 NumPy 数据：

```bash
python3 tools/preprocess_datasets.py --datasets dsg
```

已有 `processed/dsg/` 结果需要重新生成时，为该命令添加 `--overwrite`。

## 输出接口

结果保存在 `processed/dsg/`，其中 `xsub/` 和 `xview/` 分别提供训练集与测试集：

```text
processed/dsg/
|-- metadata.json
|-- xsub/
|   |-- train_data.npy
|   |-- train_label.npy
|   |-- train_label.pkl
|   |-- train_samples.txt
|   |-- train_manifest.jsonl
|   `-- test_...（文件类型相同）
`-- xview/（与 xsub 结构相同）
```

- `*_data.npy`：`float32` 骨架序列，形状为 `(N, 3, 300, 25, 2)`，通道顺序为 `x、y、z`。
- `*_label.npy`：与数据逐样本对应的 `int64` 标签，取值为 `0-4`，映射见上方类别表。
- 其余文件用于记录样本名称、处理信息和数据统计，通常无需作为模型输入。

数据文件**不包含骨架边连接**。模型需要根据 NTU RGB+D 25 关节拓扑构建帧内邻接关系，并自行建立相邻帧之间的时间关系。
